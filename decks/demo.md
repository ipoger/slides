# 一些细节

----

## 代码可以直接放

```python
def hello(name: str) -> str:
    """幻灯片里的代码块会自动高亮。"""
    return f"hello, {name}"
```

+ 支持行内公式 $O(n\log n)$
+ 支持列表、表格、引用、图片

----

## 公式也可以

$$
T(n) = 2T(n/2) + O(n) = O(n\log n)
$$

+ 用 `$...$` 写行内公式，用 `$$...$$` 写块级公式
+ 渲染由本地 KaTeX 完成，不依赖网络
